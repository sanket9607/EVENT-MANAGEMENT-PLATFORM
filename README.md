# Event Management Platform

A full-stack event management platform that allows users to create, manage, and view events with real-time updates.

## Features

- User Authentication: Register, Login
- Event Dashboard: View upcoming events
- Event Creation: Add events with name, description, and date
- Real-Time Updates: See live attendee counts
- Responsive Design: Works on all devices

## Tech Stack

- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js, MongoDB, JWT, Socket.IO
- Deployment: Vercel (Frontend), Render (Backend)
